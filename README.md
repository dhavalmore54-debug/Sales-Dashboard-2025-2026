# Sales-Dashboard-2025-2026
Interactive Sales Dashboard for 2025-2026 built using Excel, featuring KPI tracking, revenue analysis, profit insights, regional performance, and dynamic data visualizations for business decision-making

## Tools Used
- Microsoft Excel
- Data Visualization
- Data Cleaning

## Dashboard Features
- Total Sales Analysis
- Profit & Revenue Tracking
- Region-wise Performance
- Monthly Sales Trends
- Category-wise Insights
- Interactive Filters and KPIs

## Key Insights
- Identified top-performing regions and products
- Analyzed monthly revenue growth trends
- Tracked profit margins across categories
- Improved decision-making through dynamic visualizations
